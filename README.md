以下步骤基于 Ubuntu 22.04 或 Debian 12（在 KiwiVM 面板重装系统时选这两个，资料最多、最稳）。

**第二步：进 KiwiVM 面板记下三样东西。** 用户中心 → My Services → Open KiwiVM，把 IP 地址、SSH 端口、root 密码抄下来。特别注意：搬瓦工的 SSH 端口默认不是 22，在面板 Main Controls 页面能看到实际端口号。连不上服务器，十有八九是端口填错了。

**第三步：SSH 连接服务器。** Windows 用 Xshell 或 PuTTY，Mac 直接开终端：

bash
ssh root@你的IP -p 端口号


**第四步：安装宝塔面板。** 命令行对新手不友好，装个宝塔，后面建站、管理数据库、申请证书都能点鼠标完成：

bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec


装完会显示面板地址和初始账号密码。登录后按提示装 LNMP 套件，推荐组合 Nginx 1.22+ / MySQL 5.7 / PHP 8.1，十分钟左右装完。小内存机器更建议 Nginx，比 Apache 省资源。不想用面板的话，LNMP 一键包是纯命令行的替代方案。

**第五步：添加站点并解析域名。** 宝塔左侧「网站」→「添加站点」，填域名、勾选创建数据库——数据库名、用户名、密码记下来，装 WordPress 要用。然后去域名注册商后台把 A 记录指向 VPS 的 IP，解析几分钟到几小时生效，ping 一下域名验证。

**第六步：部署 WordPress。** 最省事的方式是宝塔「软件商店」里的一键部署，全程图形化。手动装也不难：把 WordPress 最新版压缩包解压到 `/www/wwwroot/你的域名/`，把 `wp-config-sample.php` 复制成 `wp-config.php`，填入第五步的数据库信息，然后浏览器访问域名，跟着安装向导填站点标题和管理员账号，几十秒跑完。

**第七步：收尾三件事。** 在宝塔站点设置里申请 Let's Encrypt 免费证书并开启强制 HTTPS；装一个缓存插件（比如 WP Super Cache）；在后台设置好固定链接格式。做完这些，一个能正常对外访问的 WordPress 站就齐活了。
